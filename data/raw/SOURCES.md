# Source documents

The PDFs are not committed: the IRAS guides carry a notice forbidding reproduction or storage
"in a retrieval system of any nature" without IRAS's written permission (see
`docs/PLAN.md`, Data and copyright). Fetch the files below into this folder under these
names and check the SHA-256 so everyone builds from identical sources.
